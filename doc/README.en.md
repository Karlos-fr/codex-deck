# Codex Deck

## Description

Codex Deck is a fast, lightweight native Windows client for managing multiple Codex sessions, projects, and agents from a single interface. Built with C++23, Win32, Direct2D, DirectWrite, and DirectComposition, it organizes sessions in a compact tree and opens them in a Workbench designed to follow conversations, commands, tools, approvals, and file changes without relying on a heavy web-based UI.

The project is currently in its early development stage and starts from the proven native foundation of [Codex Glass](https://github.com/Karlos-fr/codex-glass).
